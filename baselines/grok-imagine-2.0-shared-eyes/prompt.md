- The eyes must be positioned to work for both orientations
- Each face needs its own distinct nose, mouth, hair/headwear, and expression

- Add decorative elements (hats, beards, hair ornaments) to help define each face's boundaries
- Ensure both faces have complete, believable facial structures despite sharing the same eyes 

Example composition: Place the shared eyes in the center-vertical area of the image. Build the first face around these eyes in normal orientation, then carefully construct the second face using the same eyes but in inverted orientation, where the 'forehead' area of the first face becomes the 'chin' area of the second face."**
