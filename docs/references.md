## Changes made when these were verified (compared with the previous draft)

- **Shell origin (1931–32).** The earlier draft carried it only via a bookseller listing. It is now sourced to the Salisbury Museum Rex Whistler Archive [12] and no longer rests on [13].
- **Title of the 1946 book.** Written as *OHO! Certain Two-Faced Individuals* (the form in the catalogue and museum records); earlier text in this repository wrote "¡OHO!".
- **[4]** now has the Eurographics DOI, editors and page range; the description now says what the paper does (dictionary search plus an editor that enforces symmetry).
- **[6]** the title and venue were confirmed (ICDAR 2023, LNCS 14189) and a DOI and the arXiv preprint added.
- **[8]** venue, date and pages added (the earlier draft only had a URL).
- **[9]** the claim was narrowed to what the source says (early text-only GPT-4, TikZ and SVG drawing).
- **[10], [11]** page range and DOI added for [10]; [11] now lists the authors as Kris & Gombrich, the order used in a scholarly citation of the book (a scholarly article on the Kris/Gombrich caricature project, https://jjawl.bigakukai.jp/wp-content/uploads/2025/03/no29_ninomiyanozomu_36-47.pdf; the Gombrich Archive lists the book as "with Ernst Kris"); the book itself was not consulted, so the author order is the least certain detail in the bibliography.
- **[12], [13]** new entries (see above). The previous draft's own wording that [13] was "cited via bookseller records" is retained as "not consulted".
