# Reviews by a second agent

During the project, a second AI agent (a Hermes agent playing a "critic" role) reviewed the prompt between rounds, and later a draft of this repository. These notes are kept because they explain several prompt changes. They are the reviewer's opinion, not ground truth, and were not all followed.

| File | When | About |
|---|---|---|
| `review-1-after-pilot.md` | After round 0 | Prompt v1 and the three pilot outputs (summary, translated to English) |
| `review-2-after-v2.md` | After the v2 runs | Prompt v2 and its outputs |
| `review-3-on-prompt-v4.md` | Before round 2 ran | A short risk review of prompt v4 (written after the round-2 run had started and not applied) |
| `review-4-repository-draft.md` | While preparing this repository | Draft of this repository |
